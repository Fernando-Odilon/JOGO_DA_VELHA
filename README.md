# ❌⭕ Jogo da Velha (Tic-Tac-Toe) - Refatoração em React

## 🎯 Objetivo do Projeto
Este projeto tem como objetivo refatorar e modernizar o tradicional **Jogo da Velha** apresentado na documentação oficial do React[cite: 1]. 

A proposta é evoluir o código legado[cite: 1], aplicando as melhores práticas de desenvolvimento web moderno[cite: 1]:
- **Componentização e Composição** organizadas em pastas dedicadas.
- **Estilização modular e reutilizável** (CSS Modules + BEM + Variáveis CSS + Bootstrap).
- **Acessibilidade (a11y)** e HTML semântico.
- **Boas práticas de Clean Code** e legibilidade de código.

---

## 🛠️ Tecnologias e Estratégias Utilizadas
- **React**: Biblioteca principal para construção da interface baseada em componentes.
- **Vite**: Ferramenta de build rápida e moderna para desenvolvimento Front-end.
- **JavaScript (ES6+) & JSX**: Sintaxe moderna para lógica de componentes e renderização declarativa.
- **HTML5 Semântico**: Estruturação acessível do jogo (`<main>`, `<header>`, `<button>`, etc.).
- **CSS Modules + BEM**: Estilização isolada por componente evitando conflito de classes, aplicando a metodologia Block Element Modifier.
